xe-exporter

A high-performance Prometheus and OpenTelemetry exporter for Intel Arc GPUs

This exporter provides detailed metrics about Intel Arc GPUs (Battlemage and Alchemist) using the modern Linux xe kernel driver.

OTel Native

Built using the OpenTelemetry Go SDK for unified metrics collection and standardized observability.

Dual Export

Supports both Prometheus (/metrics endpoint) and OTLP gRPC push for flexible monitoring setups.

Real-time Monitoring

Collects VRAM, frequency, power, temperature, fan, throttle metrics in real-time.

Systemd Ready

Includes a pre-configured service file for easy deployment and management.

Key Features

  • Enhanced VRAM Discovery: Supports Linux 7.0+ debugfs tile*/vram_mm VRAM discovery
  • Improved Sensor Discovery: Auto-discovers hwmon temperature and power limit sensors
  • Multi-GPU Support: Works with multiple GPUs in the system
  • Throttling Diagnostics: Reports frequency throttling status and reasons
  • Optional PMU Metrics: GPU engine busyness percent via xe PMU (requires -enable-pmu)

Installation

# Build from source make build sudo make install # Setup as a service sudo make setup-service

Configuration

The exporter is configured via /etc/default/xe-exporter:

# /etc/default/xe-exporter XE_EXPORTER_OPTS="-prom-port 9101 -otlp-endpoint my-otel-collector:4317"

Available Metrics

Metric Name Description Labels
xe_gpu_vram_total_bytes Total VRAM capacity card, vram
xe_gpu_vram_used_bytes Current VRAM allocation card, vram
xe_gpu_gt_usage_percent GPU GT utilization percent card, gt
xe_gpu_engine_busy_percent GPU engine busyness percent via xe PMU (requires -enable-pmu) card, gt, engine
xe_gpu_frequency_actual_mhz Actual clock speed card, gt
xe_gpu_power_watts Power draw (non-blocking energy delta) card, type
xe_gpu_temperature_celsius Temperature sensor reading card, sensor
xe_gpu_throttle_status Frequency throttle status (0 = unthrottled, >0 = throttled) card, gt
